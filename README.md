# Skill Timer Pro

Create a habit tracker that allows for different skills, notes the date and time, has a customer timer for timed execution of a skill that then asks for a total number of executions done during that time, and logs the date and time of the activity, amount of time on the timer, and number of executions within that timeframe.

This project was built with [Lovable](https://lovable.dev).
